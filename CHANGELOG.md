# Changelog

User-visible builds of Dukaan Dost, newest first. Generated by `scripts/changelog.mjs` from git tags and `MD/builds/`; don't edit by hand. Internal changes (InBuls) aren't listed.

## Build 1007 · 2026-11-02
**Pages built from components, with a bento and glass design, a hideable menu and a fair yesterday comparison**

The call page and the dashboard are now built from small components that the server stitches together when a page is served. They have a new look that mixes a bento grid, glass for the menu and bars, and hard-edged accents on the call button and the hero Sales figure. The dashboard menu is a curved drawer that slides out and can be hidden, with a theme switch (Auto, Light, Dark) on both pages. The dashboard compares today with yesterday up to the same time of day, shows loading placeholders instead of blank panels, and folds the needs-attention count into its panel.

[Report](MD/builds/build-1007.md)

## Build 1006 · 2026-11-02
**One shared colour palette for the call page and the dashboard**

Both pages now use the Kirana Green palette: white cards on a pale slate page, green for the brand and active states, blue for sales and processing, violet for credit, amber for pending and red for errors and End call. Dark themes follow the same palette.

[Report](MD/builds/build-1006.md)

## Build 1005 · 2026-11-02
**Call page and dashboard redesign, with a live transcript**

The call page is now a call screen with a timer, listening/thinking/speaking states, a waveform, a live transcript and an order panel. The shopkeeper dashboard has a side menu, icon tiles with change since yesterday, a 7-day sales chart and a needs-attention list. The server sends the caller's words and the agent's sentences to the page as they happen.

[Report](MD/builds/build-1005.md)

## Build 1004 · 2026-11-02
**Gnani speech backends, the demo shop, and fixes found by the research**

Prisma (listening) and Timbre (speaking) can now be switched in with STT_PROVIDER=gnani and TTS_PROVIDER=gnani. The agent has a demo kirana shop with a 61-item stock list in English, Hindi and Telugu. Three defects are fixed: a price was split from its currency word, an interrupted reply was remembered as fully heard, and Hindi and Telugu words were cut into pieces by the knowledge search. The dashboard shows when a customer is on a call.

[Report](MD/builds/build-1004.md)

## Build 1003 · 2026-10-28
**Shopkeeper dashboard, and one agent for many shops**

Each shop now has its own call link (/s/<shop>/) and a PIN-protected dashboard (/s/<shop>/dashboard) that shows orders, credit balances and loan enquiries live. One running agent serves any number of shops, loading each call's own prompt, stock list and greeting.

[Report](MD/builds/build-1003.md)

## Build 1002 · 2026-10-28
**Run as software only: call from a browser, Raspberry Pi support removed**

You now place a test call from a browser tab: python -m dukaan_dost serves a call page, and the microphone and the agent's replies travel over a WebSocket. The Raspberry Pi and Bluetooth setup, and the Pi install scripts, are gone.

[Report](MD/builds/build-1002.md)

## Build 1001 · 2026-10-28
**Gnani and Gemini keys, Gemini by API key, call recording off by default**

The agent can now run on a Gemini API key with no Google Cloud project, and the Gemini model is a setting that defaults to a current model on that path. The config and requirements are ready for Gnani, and calls are no longer recorded unless someone turns recording on.

[Report](MD/builds/build-1001.md)

## Build 1000 · 2026-10-28
**Baseline: Smart Caller voice agent, de-identified**

The starting point for Dukaan Dost: the Smart Caller phone agent at its latest upstream version (2026-08-19), with every client name taken out. It answers calls in Telugu, Hindi and English with Sarvam STT, Gemini on Vertex AI and Google TTS.

[Report](MD/builds/build-1000.md)
